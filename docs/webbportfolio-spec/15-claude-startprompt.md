# Claude Startprompt

Kopiera detta till Claude när projektet ska tas över.

```text
Du ska ta över arbetet med Webbportfolio från ett färdigt generator- och specifikationspaket.

Läs först:

1. 00-claude-takeover.md
2. 14-ai-arbetsbord-och-rollfordelning.md
3. README.md
4. 01-projektbrief.md
5. 12-forsta-diskussionen-tolkning.md
6. 13-katalogstruktur-och-prioritering.md
7. 11-variationsmatris.yaml
8. 03-sidstruktur.yaml
9. webbportfolio-spec.json

Läs därefter branschbriefarna i hemsidor/ när du behöver bygga respektive demo.

Målet är att skapa en kodad Webbportfolio-webbplats som fungerar som en digital utställningslokal och interaktiv webbplatsstudio.

Viktigt:

- Webbportfolio ska vara ett eget projekt och inte en kopia av Nova IT.
- Nova IT får nämnas diskret som avsändare.
- Använd inte Nova IT:s repo, drift, DNS, secrets, zoner eller interna system som tekniskt beroende.
- Publicera inte utan uttryckligt beslut.
- Ändra inte DNS, domäner, e-post, betalning, abonnemang eller säkerhetsinställningar.
- Använd inga verkliga kunduppgifter, verkliga caféuppgifter, hemligheter eller externa tjänster.
- Demos får inte vara samma mall med olika färger. Varje demo ska ha egen layout, ton, bildspråk, CTA-strategi och branschlogik.
- Simulerade funktioner ska märkas som demo och får inte framstå som verkligt inkopplade.

Rekommenderad första byggordning:

1. Webbportfolio-skal och katalog.
2. Café - komplett demo.
3. Konsult - komplett demo.
4. Hantverk/lokal service - komplett demo.
5. Gemensamt system för demobar, status, katalogkort och simulerade funktioner.
6. Webbshop och tandvård som nästa kompletta demos.
7. Övriga demos som förhandsvisningar eller brief-ready tills de byggs färdigt.

Innan du kodar:

- inventera repo och teknikstack,
- kontrollera package manager,
- kontrollera git status,
- skapa en kort implementeringsplan,
- fråga bara om något kräver större beslut eller extern behörighet.

När du är klar med ett steg:

- lista ändrade filer,
- lista körda tester,
- säg vad som är byggt,
- säg vad som är simulerat,
- säg vad som återstår,
- säg om något kräver beslut.
```
