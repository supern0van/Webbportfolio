# Arbetsorder - Första Bygget

Den här filen är en konkret första arbetsorder för Claude när ett repo finns eller ska skapas.

## Mål

Skapa första kodade versionen av Webbportfolio med stabil grund, katalog och tre kompletta demos.

## Omfattning

Bygg:

- Webbportfolio startsida.
- Webbplatskatalog med tolv demoingångar.
- Gemensam demobar.
- Statussystem: `ready_demo`, `build_next`, `brief_ready`.
- Café som komplett demo.
- Konsult som komplett demo.
- Hantverk/lokal service som komplett demo.
- Simulerade funktionsval med tydlig demomärkning.
- Startpriser med `X XXX kr`.
- Kontaktsektion utan verkligt aktiv extern integration.

Bygg inte ännu:

- publicering,
- DNS,
- verkliga formulär,
- verklig bokning,
- verklig betalning,
- externa kartor,
- nyhetsbrevstjänst,
- riktiga priser.

## Acceptanskriterier

Första bygget är godkänt när:

- startsidan visar Webbportfolio som utställningslokal,
- katalogen visar tolv demos i kategorier,
- Café, Konsult och Hantverk öppnas som egna världar,
- varje komplett demo skiljer sig tydligt i layout och ton,
- simulerade funktioner är märkta som demo,
- mobilvy fungerar utan överlapp,
- inga verkliga personuppgifter eller kontaktuppgifter används,
- inget publiceras automatiskt,
- tester/build körs och rapporteras.

## Särskild granskning

Granska särskilt att:

- Webbportfolio inte ser ut som Nova IT,
- Nova IT-hänvisningen är diskret,
- demos inte känns som samma mall,
- prisdelen inte hittar på riktiga priser,
- kontakt- och bokningsflöden inte låtsas vara aktiva.
