# Priser och Konvertering

## Prisdel

Rubrik:

> Startpriser

Intro:

> Priserna är platshållare i detta utkast och ska beslutas innan de används i skarp kommunikation.

## Prisnivåer

### Enkel landningssida

Pris:

> från X XXX kr

Beskrivning:

> För verksamheter som behöver en tydlig startsida med kontaktväg, grundläggande presentation och mobilanpassad design.

### Komplett företagswebbplats

Pris:

> från X XXX kr

Beskrivning:

> För verksamheter som behöver flera sidor, tydligare struktur, tjänstepresentationer och mer innehåll.

### Webbplats med bokning eller andra funktioner

Pris:

> från X XXX kr

Beskrivning:

> För verksamheter som vill bygga vidare med funktioner som bokning, formulär, återkommande innehåll eller andra praktiska flöden.

## Möjliga tillägg

- Kalender eller bokning
- Formulär
- Hjälp med text och bilder
- Löpande underhåll

## Kontakt-CTA

Rubrik:

> Vill du se vad som passar din verksamhet?

Text:

> Börja med ett samtal om behov, innehåll och vilka funktioner som faktiskt hjälper besökaren.

Knapp:

> Kontakta oss

## Regler

- Hitta inte på riktiga priser.
- Behåll `X XXX kr` tills beslutade priser finns.
- Ge inga löften om externa tjänster innan de är valda och tekniskt godkända.
- Formulär och integrationer ska beskrivas som möjliga tillägg, inte som redan aktiva.
